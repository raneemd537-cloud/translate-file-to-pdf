# translate-file-to-pdf

A Grok skill that translates any file (PDF, DOCX, TXT, images with text, etc.) into a clean, well-structured PDF while preserving the original document structure.

---

## Description

This skill enables Grok to translate any uploaded file into a clean and well-formatted PDF. It keeps the original order of sections, headings, paragraphs, and lists as much as possible.

---

## How to Use

1. Upload the file you want to translate.
2. Use one of the following phrases (or similar):

   - `Translate this file and give me a PDF`
   - `Use the translate-file-to-pdf skill`
   - `Translate the attached document to Arabic and return a PDF`
   - `Translate this file using translate-file-to-pdf`

3. Grok will translate the content and provide a downloadable PDF.

> **Note:** If no target language is specified, the default translation language is **Arabic**.

---

## Features

- Supports PDF, DOCX, TXT, and image files containing text
- Preserves document structure (headings → paragraphs → lists)
- Defaults to Arabic translation (other languages supported)
- Generates a clean, professional PDF with page numbers
- Designed for repeated use without re-explaining the workflow


---

## How to Install

1. Copy the `SKILL.md` file
2. Place it in your skills directory:
3. Restart the session or invoke the skill directly.

---

## Notes

- This skill is designed to work with Grok.
- For best results, use files with clear, extractable text (avoid low-quality scanned images).
- Very long documents may be processed in sections and then combined into a single PDF.
